## 反馈问题

本仓库用于收集 MiniMax Code 桌面端的问题反馈。

> 提交 Bug 时，请在「设置 → 通用 → 上传日志」上传日志，并附上生成的 uploadId。

### 提交步骤

1. 点击右上角 **Issues** → **New issue**
2. 选择对应模板（Bug / Feature / Question）
3. 填写以下信息：
   - **版本号** —— 在「设置」中可见
   - **平台** —— macOS / Windows
   - **uploadId** —— 在「设置 → 通用」上传日志后生成
   - **复现步骤** —— 简短、可复现
   - **截图或日志** —— 可选，但有则更佳

### 提交前请确认

- 搜索一下，确认没有重复 Issue
- 已升级到最新版本
- 已移除敏感信息（API Key、Token 等）
